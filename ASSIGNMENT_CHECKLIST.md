# Проверка требований задания

Этот файл нужен для быстрой самопроверки перед сдачей.

- [x] Предметные сущности оформлены классами.
- [x] Сущности наследуются от абстрактного базового класса.
- [x] Для атрибутов используются свойства с геттерами и сеттерами.
- [x] Реализованы `__eq__`, `__repr__`, `__str__` и дополнительные специальные методы.
- [x] Объекты книг можно сравнивать и сортировать.
- [x] Вместо `dict` используется собственный `CustomMap`.
- [x] В начальном каталоге больше 10 объектов книг.
- [x] Интерфейс содержит больше 5 типов UI-компонентов.
- [x] Переопределены не менее 10 компонентов Qt.
- [x] Компоненты размещены через layout-менеджеры.
- [x] При закрытии создается отчет с полями `login`, `time_in`, `time_out`.
- [x] Время отчета имеет формат `%d.%m.%Y %H:%M:%S`.

Техническую проверку можно запустить командой:

```powershell
py -3 tools/check_requirements.py
```
